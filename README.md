# Name:  FitLog

## Short Description
FitLog is a workout management web application designed to help users easily browse and manage their workouts. Users can explore different exercises, view detailed workout information, add exercises to their daily plan, save workouts for later, and sort their selected workouts based on duration, calories, or rating.

## Technologies Used
- Next.js
- React
- Tailwind CSS
- JavaScript
- React Context API
- React Hot Toast

## Key Features
1. Browse different workout exercises
2. View detailed information about each workout
3. Add workouts to Today's Plan
4. Save workouts for later
5. Sort workouts by duration, calories, or rating
